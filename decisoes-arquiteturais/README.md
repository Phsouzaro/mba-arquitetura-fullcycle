# Architecture Decision Records (ADRs)

Registros das decisões arquiteturais tomadas nos projetos.

Padrão de nome: `0001-titulo-da-decisao.md`.

Cada ADR deve conter contexto, decisão, alternativas consideradas, consequências e status.

Utilize o [modelo de ADR](../templates/adr.md). Não registre decisões hipotéticas como se já tivessem sido implementadas.
